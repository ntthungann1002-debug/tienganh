BLOOM ENGLISH A2
================
Mở file index.html bằng Chrome, Edge hoặc Firefox để học.
Các file index.html, style.css, data.js, script.js phải nằm chung thư mục.
Website không cần máy chủ hay tài khoản. Dữ liệu sao/điểm được lưu bằng localStorage trên trình duyệt hiện tại.
Muốn đăng lên GitHub Pages: tải toàn bộ 4 file lên một repository và bật Settings > Pages.
Phần lý thuyết bám sát ảnh tổng hợp; một số ví dụ và câu hỏi được bổ sung để luyện tập.
